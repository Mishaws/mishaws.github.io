# Michael Christian — Portfolio

Minimalist research × industry portfolio built with **React**, **TypeScript**, **Vite**, **Tailwind CSS v4**, and **TanStack Router**, deployed on GitHub Pages.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## GitHub Pages Deployment

Push to the `main` branch of `Mishaws/Mishaws.github.io` and enable **Settings → Pages → Source: GitHub Actions**. The workflow in [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) builds and publishes automatically to `https://mishaws.github.io/`.
